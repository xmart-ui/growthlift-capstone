# Expense Tracker

## Project Description

Expense Tracker is a full-stack MERN application that allows users to manage their daily expenses. Users can add, edit, delete, and view expenses while tracking their total spending through a simple and responsive interface.

---

## Features

- Add Expense
- View Expenses
- Edit Expense
- Delete Expense
- Total Expense Summary

---

## Tech Stack

### Frontend
- React (Vite)
- Tailwind CSS
- Axios
- React Router DOM

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
