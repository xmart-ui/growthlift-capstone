# PROJECT_BRIEF

## Project Name

**Smart Expense Tracker**

### One-Line Description

A MERN-based web application that helps users manage, organize, and track their daily expenses through a secure and user-friendly interface.

---

## Target User

This application is designed for students, freelancers, and small businesses and individuals who want to keep track of their daily spending, monitor expenses, and manage their personal finances efficiently.

---

## Core Features

1. User Authentication (Register & Login)
2. Add, Edit, and Delete Expenses
3. View All Expenses in a Dashboard
4. Calculate Total Expenses
5. Search and Filter Expenses by Category

---

### Backend

* Node.js
